## 操作（三则）

1. **按下。** 系统触点映射到浅格区；命中 **stable** 格为起点并锁色。未命中则不起划。  
2. **方向。** 参考格心 → 此刻手指；只加四邻（过共享边 / 进格）。对角非法。45° 走楼梯。已有来时轴则滞回。  
3. **抬手确认。** 途中不定局。松手再判：路径上 stable 格 **≥2** 确认消除并下落（可变色子换色续连；魔法子本划全同色）；&lt;2 作废。有变色散消则先倒数选中再一起消。无道具 ≥5 / ≥10 路径飞入队尾出变色 / 魔法；用变色连 ≥10 也出魔法。第二指中断不算抬手。邻列在掉时，静止子仍可划。
