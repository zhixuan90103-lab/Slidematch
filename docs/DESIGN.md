# 玩法 — 最长路径消除

玩法真源。权威顺序见 [SPEC.md](./SPEC.md)。与底座冲突时玩法让步给 `AGENTS.md`；网格以本文 **9×9** 为准（覆盖初稿 10×10）。

## 定位

无尽滑动消除：在网格上单指连同色，追求最长路径。规则极简，爽点在手感和长度；道具提供跨色与爆发，并用引爆把盘面拉回可控。

## 棋盘

| 项 | 值 |
|----|-----|
| 网格 | **9 × 9** |
| 颜色 | 现 **5** 种：红心、金饼、蓝甜甜圈、紫果冻、绿马卡龙 |
| 连接 | 八向，可拐弯，必须连续 |
| 有效消除 | ≥3 同色 |
| 结算 | **仅抬手**；滑动中不消子、不生成/触发道具 |

美术：颜色第一识别，点心剪影第二。视觉框与逻辑 9×9 分离。见 [BOARD.md](./BOARD.md)。

## 核心循环

1. 找最长同色路径  
2. 按下并滑动；长度上去则视 / 震 / 声加码（过档封顶）  
3. 抬手：整条路径一起消  
4. 按长度在消除附近生成道具（**当次不能用**）  
5. 重力补洞、顶补；**整盘 stable 后**才接下划  
6. 下次可用道具跨色、引爆同类  
7. 刷分，重复  

没有落地后再自动三消。

## 路径（阶段 B）

按下选起点和颜色 → 每次滑动从队尾再判 → 八向（来时方向粘滞）决定加哪一格，沿该向过半步且同色未入队则加（能加先加）→ 只许退上一格且须在上一格旁 → 中部不可再入 → 抬手 ≥3 结算，&lt;3 取消。

不加全盘最近格、不预筛连通块。田字格斜划不先吃横竖。手感实现见 [OPERATION.md](./OPERATION.md)。

## 下落

全局统一重力；格子 `current` + `incoming`；一格逻辑一子；正下方能接才打开上方子。详见 [DROP.md](./DROP.md)。

## 道具（未全部定点，阶段 E 前必须拍板）

| 路径长度 | 等级 | 效果 |
|----------|------|------|
| 6～7 | 1 | 变色续连 |
| 8～9 | 2 | 变色 + 大范围爆炸 |
| ≥10 | 3 | 变色 + 全盘清 |

当次不吃刚生成的。使用可引爆同类。

仍未定：占格还是叠在子上、1 级变成哪色、爆炸形状、「同类」范围、生成落点、第 5–6 色时机。  
9×9 上 ≥10 比初稿 10×10 更难，可玩后再调档，不改语义。

## 分数（原则，数字未定）

路径长度（基础 + 倍率）+ 消除数 + 用道具加分。无尽刷高分。

## 反馈

档与道具阶梯对齐（约 6 / 8 / 10）。过档封顶。滑动中只做视听触，不触发规则效果。
