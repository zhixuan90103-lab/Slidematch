## 定位

无尽滑动消除：在网格上单指连同色，追求最长路径。规则极简，爽点在手感和长度。道具未定点，不做。

## 棋盘

| 项 | 值 |
|----|-----|
| 网格 | **6 × 6** |
| 颜色 | **3**：蓝水滴、绿叶、橙太阳 |
| 连接 | **四向**（只横竖），可拐弯，必须连续；对角非法 |
| 有效消除 | **≥2** 同色 |

视觉框与逻辑 6×6 分离。见 [BOARD.md](./BOARD.md)。

## 核心循环

1. 找最长同色路径  
2. 按下并滑动；长度上去则视 / 震 / 声加码（过档封顶；档反馈未做）  
3. 抬手：整条路径一起消  
4. 重力补洞、顶补  
5. **静止子随时可划**；正在下落 / 消除 / 生成的子不可划  
6. HUD 记下当次路径长度；重复  

没有落地后再自动三消。变色子见下文；爆炸 / 全盘清未定点。

## 路径

操作模型（简化）。像素、粘滞角、插值见 [OPERATION.md](./OPERATION.md)。

**1. 按下**  
系统给出屏幕触点。网页将其映射到浅格区，判定落在哪一格；该格为路径起点，并锁定本划颜色。未命中有效格（或该格不是 `stable`）则本帧不起划。

**2. 方向**  
方向向量恒为：参考格心（起划为起点，其后为队尾）指向此刻手指。只认 **上 / 下 / 左 / 右** 四邻。加格：越过队尾与该邻的共享边，或指针进入该邻格（spacing=0 时两者同一件事）。对角邻居非法。45° 斜划按过边顺序走楼梯。已有来时轴时滞回：另一轴须明显更大才改轴，以免格内心微振。

**3. 抬手确认**  
滑动途中不定局。手指离开屏幕时，以抬手点作最后一次判定：链上 **stable 同色格 ≥ 2** 则确认整条路径并消除；不足 2 则本划作废。第二指引起的系统中断不算抬手。

其后：从队尾四邻加格（过边/进格、同色、未入队则加）；只许退上一格且须在其旁；中部不可再入。不加全盘最近格、不预筛连通块。田字格斜划走楼梯，不连对角。

## 下落

格子 `current` + `incoming`，一格一子，正下方能接才打开上方子。运动：初速 / 加速度 / 上限（默认 600 / 1400 / 1600）。详见 [DROP.md](./DROP.md)。

路径只认 `stable`。邻列在掉时，已静止的子仍可滑动消除。

## 分数（占位）

HUD 标题 **SCORE**，数字为 **当次有效路径长度**。失败或取消回 `0`。  
累计公式、倍率、连消加分 **未定点**，不要先做排行榜。

## 道具

分两层：**特性**（所有道具都有）和 **效果**（这颗道具独有）。

**特性：颜色转化。** 占格、四向可划入。过它之后下一格可换锁定色。从它起划：第一颗普通子锁定颜色。

**变色子（≥5）效果：清一种颜色。** 路径里带着它抬手：先消路径，再清盘上剩余的 **抬手锁定色**（蓝→道具→绿，清绿）。

**清盘子效果：全盘清。** 路径里带着它 **且长度 ≥10** 才全盘清。不够长：只消路径，清盘子被吃掉、不触发全盘。

生成：

- 路径 **没有道具** 且 ≥5：队尾出变色子。
- 长度 ≥10：队尾出清盘子（即使用了变色子）。用了清盘子本身：不再生成。
- 用了道具且 <10：不再出变色子。
- 当次不吃刚生成的。顶补不会出道具。

染色方案先不用。爆炸不做。

## 反馈

档与道具阶梯对齐（约 6 / 8 / 10）。过档封顶。滑动中只做视听触，不触发规则效果。阶段 D 未做。
