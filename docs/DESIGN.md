## 定位

无尽滑动消除：在网格上单指连同色，追求最长路径。规则极简，爽点在手感和长度。道具服务于更长路径（变色散消、魔法本划全同色）。细则 [ITEMS.md](./ITEMS.md)。

## 核心循环

1. 找最长同色路径  
2. 按下并滑动；基础选中见 [FEEDBACK.md](./FEEDBACK.md)。长度 6/8/10 档视+震未做。  
3. 抬手：基础消除（缩没再出碎屑）；变色见 ITEMS + FEEDBACK  
4. 重力补洞、顶补  
5. **静止子随时可划**；正在下落 / 消除 / 生成的子不可划  
6. HUD 记下当次路径长度；重复  

没有落地后再自动三消。变色子 / 魔法子见下文。爆炸 / 按钮式全盘清不做。

## 路径

操作模型（简化）。像素、粘滞角、插值见 [OPERATION.md](./OPERATION.md)。

**1. 按下**  
系统给出屏幕触点。网页将其映射到浅格区，判定落在哪一格；该格为路径起点，并锁定本划颜色。未命中有效格（或该格不是 `stable`）则本帧不起划。

**2. 方向**  
方向向量恒为：参考格心（起划为起点，其后为队尾）指向此刻手指。只认 **上 / 下 / 左 / 右** 四邻。加格：越过队尾与该邻的共享边，或指针进入该邻格（spacing=0 时两者同一件事）。对角邻居非法。45° 斜划按过边顺序走楼梯。已有来时轴时滞回：另一轴须明显更大才改轴，以免格内心微振。

**3. 抬手确认**  
滑动途中不定局。手指离开屏幕时，以抬手点作最后一次判定：链上 **stable 同色格 ≥ 2** 则确认整条路径并消除；不足 2 则本划作废。第二指引起的系统中断不算抬手。

其后：从队尾四邻加格（过边/进格、同色、未入队则加）；只许退上一格且须在其旁；中部不可再入。不加全盘最近格、不预筛连通块。田字格斜划走楼梯，不连对角。

## 下落

格子 `current` + `incoming`，一格一子，正下方能接才打开上方子。运动：初速 / 加速度 / 上限（默认 600 / 1400 / 1600）。顶补低分抄下邻/左邻成团，分数过过渡带后黏性降到均匀（不反亲和）。详见 [DROP.md](./DROP.md)。非魔法划若把盘上该锁定色清光，这一波顶补不出该色；常规消不改色池。魔法清屏不禁色，顶补仍至少 3 色。补满后若无 ≥2 同色四向则最少改两格。

路径只认 `stable`。邻列在掉时，已静止的子仍可滑动消除。

## 分数

HUD 右 **SCORE**、左 **COINS**（标题同色同字）。数字 **ease-out 滚动**（`scoreRollMinSec`–`scoreRollMaxSec`）。不要先做排行榜。设置左下齿轮。

实现：`src/game/score.ts`。

```
单价 unit = max(1, 抬手前本局金币)     （0 金当 1；本划新得的金币下一划才进单价）
n = 路径格 + 变色散消的格
当次 = unit × n
变色 / 魔法不另乘倍率

滑动中：SCORE 不预览、不加分。
开始消除时：新累计 = 旧累计 + 当次；HUD Rolling 加到新累计（变色散消等倒数结束再滚）。
取消 / <2：不加分。
```

**金币（本局）：** 仅魔法有效抬手。路径每格 +`coinPerMagicCell`（默认 1）。盘上白板金币 overlay 全路径都在。飞向 HUD 图标：条数 ≈ 路径 × `scoreFlyKeep`（**2/3**，只少飞的，不减盘上的）；终点大小 = 图标 × `scoreFlyEndMul`（**0.55**）；路程 `scoreFlyFadeStart`（**0.62**）起淡出，到达时已透明。每枚打中 punch + rolling（credit 均分）。变色散消格、普通划不加。刷新盘面从 0 计。无滑动预览。

魔法优先于变色，不叠乘。

**色数：** 开局 3 色（水滴 / 叶 / 太阳）。**分数不解锁色种。** 路径含魔法且抬手有效后，顶补色种只 **±1**，夹在 **3–5**（3 只能到 3 或 4）。降档约 55%，加档约 45%。变色、普通划不改色种。第 4 心、第 5 星。已在盘上的子不改色，只影响新落下的。

## 道具

真源：[ITEMS.md](./ITEMS.md) · `src/game/items.ts`。本文不重复算法。

- 共性：占格、四向可划入、划过可换锁色。
- 变色子：抬手消路径，再按路径长度散消锁定色（落单优先）。不是整色清场。
- 魔法子：本划全同色、全盘 yaw 翻成白板；抬手只消路径。有效抬手后顶补色种 ±1（细则 [ITEMS.md](./ITEMS.md)）。
- 同路有魔法：只走魔法，不出新道具。路上只有变色且 ≥10：仍出魔法。无道具：≥5 变色、≥10 魔法。
- 爆炸 / 按钮式全盘清不做。
