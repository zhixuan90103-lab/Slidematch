## 基础选中

命中 `stable` 才起划。未命中无反馈。

- 放大到 **1.05**，上浮 **6px**，弹簧（刚度 480 / 阻尼 12 / 初速 7.5），选中时转速跟弹簧速度走。
- Additive `plus-lighter`，透明度 **0.18** × 选中进度。变色散消标记 **0.1**。
- 选中棋子右上角圆形角标 = 入队顺序。颜色跟当前滑动锁色。散消格不标。
  - 普通 **18** / 队尾 **30** / 外伸 **9**。DOM 盒固定 30，视觉用 `scale`
  - **出现、队尾放大/缩小**：`badgeSnapSec` **120ms** ease-out，到点即停，不要后半段慢慢蹭
  - **消失**（倒数从后往前、或划退掉格）与棋子取消相同：`outSec` **150ms** ease-out
- 其它色透明度 **0.5**，过渡 **80ms**。投影随变暗关掉，松手 **100ms** 淡入（`shadowInSec`）。
- 浮稳后待机：±**0.3px** 起伏。
- 再划已选中格：下沉弹簧再弹回（回退到队尾也会触发）。新入队第一下不叠下沉。
- 无效抬手（&lt;2）：**150ms** ease-out 缩回+落下。有效抬手：**跳过归位**，从悬浮进消除。
- 震动（`FEEL.haptic`）：按下瞬态 **0.55 / 0.86**；过格与回退 **0.35 / 0.50**；变色散消每点一颗散子 **0.30 / 0.40**；有效抬手找对 pattern（瞬态 0.50/0.30 → 隔 50ms → 持续 100ms 0.40/0.19 收到 0）。取消 / &lt;2 / 第二指中断 **不震**。

## 基础消除

只消被选中的格（路径；变色再加散消名单）。

1. 缩小 **150ms** ease-in 收到 0；贴图保持**抬手那一刻的显示**（换锁色后的新色 / 魔法贴图）。**缩的时候格子不放**（上方不落）。
2. 缩完才腾格，并在格心 **圆形发射器** 出碎屑。
3. 碎屑 **3–5** 粒，造型随机（圆/胶囊/菱形/三角/芯片），颜色=**抬手那一刻的显示色**（换锁色后的贴图色 / 魔法贴图，不是逻辑色），立刻出现，整段寿命淡出，重力下落，独立于棋子隐藏。
4. 有效抬手走找对震动（`FEEL.haptic` find pattern），不是 UIKit `medium`。

## 翻牌（共用规格）

换锁色、魔法底板、魔法回翻、金币回翻 **共用这一套**。不要另写 6+6 或拆两段缩放。

| 项 | 值 |
|----|----|
| 时长 | 正向 `recolorSec` **200ms**；魔法取消翻回 `recolorBackSec` **300ms** |
| 前段 | 当前外观 `00–06`（7 帧，正面→侧棱） |
| 后段 | 目标外观 `19–23`（5 帧，侧棱→正面）再静图（横条末格） |
| 缩放 | 绕图片中心，`1 → recolorScale(1.35) → 1`，峰值在侧棱（`sin(πu)`） |
| 选中 | 翻的过程中保持路径选中（1.05 / 上浮 6px） |
| 投影 | 翻的 200/300ms 内 `filter: none`，停稳恢复。原色子藏掉后不再更新它的 transform/yaw |
| 逻辑色 | 不变。只换贴图。 |

素材：`yaw-2d/<套>/yaw_strip.png`，12 帧动画 + 末格静图。DOM 只改 `background-position`。换锁色在第 7 帧换一次横条（from→to）。魔法见下一节：原色子**不换**白板横条。

实现：`convertRecolorLook` / `convertPieceLook` / `convertBlankLook` / `convertRecolorScale`。出池必须换新 `piece.id`。

有效抬手开始消：先记下当时显示色（`clearLook`），再丢掉路径格翻面（不反向播）。

## 变色子表现

规则见 [ITEMS.md](./ITEMS.md)。

**滑动中**

- 散子不浮。Additive **160ms** 淡入标记（`markGlow` 0.1）；摘名额则淡出。
- 不出手指气泡。入队顺序看棋子右上角标。
- **换锁色：** 路径含变色、无魔法、锁色已定 → 路上普通子走翻牌共用规格。变色子自己不播。回退反向。

**松手有效且有散消**

1. 倒数：路径角标**从队尾往起点**逐个缩小消失。有散子时每 **70ms** 消 1 个角标并选中 1 颗散子（`tickSec`）。散子选完后剩下的角标在 **120ms** 内从后往前收完（`tickEmptySpan`）。散子停住 **1.1 / 9px**，过冲 `popVel` 24，无旋转晃。
2. 全部散子发出选中后再停 **500ms**（`holdSec`）。
3. 路径 + 散子一起消。倒数期间不接受新划。

无散消：松手立刻基础消路径。

## 魔法滑动（三层）

逻辑色不变。平时魔法子仍是 `piece-magic.png`。

| 层 | 是什么 | 换图规则 |
|----|--------|----------|
| 底板（原色子） | 自己的色条 | 魔法时只播 `00–06` 侧棱后藏透明度；**不换成白板横条** |
| 白板 overlay | `magic_bai` 横条 | 进局预铺 36 张；非魔法 `opacity: 0`；翻入播 `19–23` |
| 金币 overlay | `yaw-2d/coin` 横条，末格 `coin.png` | 同 36 张池；延迟 100ms 出场；yaw 400ms；0.4→1.2→0.9 |

对象池：金币 / 白板 / 角标 / glow / 飞分金币进局预铺 36。不用时 **`opacity: 0`**，不要 `hidden`/`remove`、不要 `translate(-9999)` 拆层。滑动变暗时 overlay 必须是 0，避免透过半透明棋子看见金币。

**Additive（路径选中）**

| 层 | 透明度 × 选中进度 |
|----|-------------------|
| 普通棋子 | **0.18**（`select.glowOpacity`） |
| 白板 | **0.05**（`convert.blankGlow`） |
| 变色散子标记 | **0.1**（`markGlow`） |
| 金币 | **不再叠** Additive 拷贝（同图再画一层划金币会卡） |

叠在当前看见的层上：白板一层；金币盖在白板上（牌面四角透明，白板必须留着）。不要叠在已藏的原色子上。

| 时机 | 白板 | 金币 |
|------|------|------|
| 点中/划入魔法 | 从**该魔法格**切比雪夫扩散翻入，每圈 50ms | 该格翻牌开始后再晚 100ms；yaw 一遍 400ms |
| 无效抬手 / 取消 / 退回路上无魔法 | 全盘一起翻回 300ms（不按圈） | 前 7 帧淡出；缩放跟底板 1→1.35→1 |
| 有效抬手路径格 | 原色子藏掉，**只缩白板**。金币一开始飞，盘上金币立刻藏，同时白板才缩。无碎屑。 | 飞向 SCORE：行差 70ms、列差 10ms；浅弧；yaw 循环；缩放前 1/3 到 1.15、后 2/3 到 0.4 |
| 有效抬手非路径格 | 全盘一起翻回原棋子（同上 300ms） | 前 7 帧淡出 |

**禁止**

- 出池不换 `piece.id`，翻面/金币会套到新子上。
- 有效抬手 `recolorFx.clear()` 掉非路径格（它们要能翻回）。
- 普通消除缩的时候露出白板/金币 overlay。

## 合成道具

普通划达到变色 / 魔法门槛时，**路径**飞向队尾再出道具；散消仍走基础消除。变色与魔法同一套，魔法略长、略大（`magicMul`）。飞入的路径子不打碎屑。

### 飞入

从路径起点依次飞向**队尾格**（不是手指像素）。队尾自己缩小。

- 单颗收缩固定 `flySec`（**170ms**，与 5 格相同）。缩小与 **alpha 淡出**同一条加速曲线（`t²`），收到 `flyOpacityEnd` **0**。
- 整段总时长对齐 `refCount`=5（约 **274ms**）；多子只压缩间隔，下限 `staggerMin`。
- 飞入子显示层级高于静止子。

### 腾格与下落

- 基础消 / 散消：缩完才腾格。
- 合成飞入：最后一颗开始飞后再过 `vacateSec`（**120ms**），路径格**一起**腾格，避免一格一格漏导致下落卡顿。
- 腾格后**各列都可以落**。道具只锁**它自己那一格**：弹出未落稳时该格不接子、道具自己不掉；同列上方的空洞照常补。
- 队尾可比飞入结束提前 `spawnLead` 弹出。

### 道具弹出

队尾从 0 过冲放大（`spawnSec` **400ms**）：放大带一点转和上移（5 格上移 **8px**）；缩回原大后原地衰减晃动（转 + 缩放 + 位移过冲回位）。路径越长过冲越大（5 格倍率 1，每多 1 格 `popAmpPer`，上限 `popAmpMax`）。弹出期间该格不可划。

变色子 / 魔法子：放大到过冲峰值前抽 `yaw-2d/convert` 或 `yaw-2d/magic`（00–06、19–23）；到最大后切回静图。缩放 / 位移 / 转曲线不改（魔法略长、略大）。

## `FEEL` 分组

| 组 | 管 |
|----|----|
| `select` | 浮起/放大/叠光/归位/暗其它/待机/再划下沉 |
| `clear` | 缩没时长、收走上浮、散消错开 |
| `convert` | 气泡、标记淡入、倒数加速、换锁色 / 魔法 overlay / Additive |
| `fx` | 碎屑数量/寿命/速度/重力/大小/发射半径 |
| `synth` | 飞入、腾格、弹出缩放/上移/转、路径长度倍率 |

改反馈只改 `FEEL` 与本文，不要在 `mount.ts` 写死数字。
