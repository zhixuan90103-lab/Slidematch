# 操作 — 手感实现规范

任何人按本文实现，应得到与当前 SlideMatch **同一套滑动手感**。  
规范地图：[SPEC.md](./SPEC.md)。玩法对错以 [DESIGN.md](./DESIGN.md) 为准；本文是 **按下 / 滑动 / 抬手** 的算法、常数、禁区和验收。  
代码真源：`src/game/path.ts` · `input.ts` · `mount.ts` · `board.ts` `cellFromLocal`。改手感先改本文常数与步骤，再改代码。

对照：SlidetoWord 只借第一指、rect、cancel 续划、`lockGestures`。不借整划射线、`along`、粘角、认词终点。

滑动中不消子。抬手 ≥2 且 stable 格足够则消除并下落（阶段 C）。邻列在掉时，静止子仍可划。

---

## 1. 坐标系（必须先统一）

- 逻辑盘 **6×6**。`(0,0)` 左上，`row` 向下，`col` 向右。
- 操作全部在 **浅格区** `.board-cells` 的 **设计像素** 里做，不是屏幕像素，不是外框 `#game-board`。
- 换算：`rect = .board-cells.getBoundingClientRect()`（已含舞台 CSS scale，**禁止再除一次 scale**）。

```
localX = (clientX - rect.left) / (rect.width  / gridWidth)
localY = (clientY - rect.top)  / (rect.height / gridHeight)
```

`gridWidth` / `gridHeight` 为设计空间格子区尺寸。`rect.width<=0` 则本帧忽略。

- 格心（原点 = 浅格区左上）：

```
sx = cellW + spacing
sy = cellH + spacing
cx = col * sx + cellW / 2
cy = row * sy + cellH / 2
```

默认：格子宽 **60**、高 **72**（360×430），`spacing = 0`。手感比例按「格宽」或「这一步的格心距」，不要写死像素。

- 单位：`unit = min(cellW, cellH)`。下文「N 格」= `N * unit`，除非写明「× 这一步格心距」。

## 2. 手势所有权（iOS）

监听挂在 **`#game-board`**（含框）。棋盘外（HUD、letterbox、桌面背景）按下 **不开始**。

- 只认 **第一指**。`setPointerCapture`。棋盘 `touch-action: none`。
- `lockGestures` + CSS：禁网页双指缩放、双击放大、长按放大镜/呼出菜单（`-webkit-touch-callout: none`）、`user-select`、SCORE 电话号码检测。单指 `touchstart`/`touchmove` 在非按钮区 `preventDefault`。设置面板仍可点。
- 系统 Home 上滑、缘滑返回、控制中心：**网页关不掉**。
- `pointermove`：若存在 `getCoalescedEvents()` 且返回非空，**按时间顺序**对每个合批点采样；否则用当前点。合批点不是第二套规则。
- `pointerup`：用松手点再走一遍滑动算法后结算。触屏 / 笔：先等 `liftGraceSec` **120ms**，窗口内再按下则续同一划（当 `move`，不新开路径）；超时才结算。鼠标立刻结算。iOS 官方没有这个窗口，是我们自己的手抖容错。
- `pointercancel`：若因第二指，用 touch 通道按同一 `identifier` 续划，**不当抬手**。无 touch 备份才真取消（名单清空）。
- 不要用 iOS `preciseLocation` 做进格（Apple：Do not use for hit testing）。
- 不要用预测点（`getPredictedEvents`）当真走过的格。
- 系统左缘「滑回上一页」是 WKWebView 原生手势，网页关不掉；不在本文手感范围内。

实现参考：`src/game/input.ts`。

## 3. 一次手势状态

```
path: 格子序列（有序、不重复）
color: 按下第一格的颜色，整划锁定
lastLocal: 上一采样的 local 坐标
```

**按下** → 只定第一格和 `color`。不预筛周围能加谁。  
**滑动** → 插值后的每个点：先加后减。  
**抬手** → 再处理松手点；stable 同色 `len(path) >= 2` 有效，否则取消。  
滑动中不消子、不生成道具。出浅格区：坐标可超出格子，路径冻在队尾，手势仍在，滑回可继续。

---

## 4. 按下：第一格

尺子：**最近格心 + 半径**，不是图标像素，不是格子矩形。

1. 用 `cellFromLocal`：在近似行列 ±1 范围内找最近格心。
2. 距离 ≤ **`0.8 * unit`** 且该格 **`stable`**（有静止同色子）→ 该格为起点，入队，锁颜色。下落中的格不当起点。
3. 更远（缝、框、两格中间谁也不够近）→ 本帧无第一格。滑动中用 **同一把尺子**，滑到够近再当起点。
4. 按下 **没有** 0.45 尾格死区。点中立刻就是队尾。

验收：正中按下只亮一格；缝上可先不亮；框上按下再滑进格子，第一格是滑入碰到的那颗。

---

## 5. 采样间插值（快划）

系统两次 `move` 之间可能跳过整格。在 **设计坐标** 里补点，每点仍走第 6 节。  
**禁止**把 8-supercover 格子列表直接加入名单（过角会带上对角格）。四向补点走 **直角折线**（4-connected walk）。

步长：`stepPx = 0.4 * unit`（`PATH_TRACE_STEP`）。不含起点、含终点。

两次采样在 **X、Y 都超过 `stepPx`** 时，禁止用对角线弦。改为 **折线**：

1. **已有来时方向** `aim = 队尾 − 上一格`（必为四向）：先沿 `aim` 走到「终点在该方向上的垂足」，再拐到终点。  
2. **尚无来时方向**（名单只有起点）：**主轴优先**——`|Δx| ≥ |Δy|` 则先水平再竖直，否则先竖直再水平。左下→右上的快跳会先经过右下（或左上）。  
3. 只有一轴超过 `stepPx`：直线。  
4. 慢速斜划：段往往不够两轴都超 `stepPx`，仍走直线 + 第 6 节过边；田字斜划应成楼梯，不连对角。

每个插值点 **最多加一格**（连加靠更密的插值点，不靠一次 `stepPath` 跳两格）。减格仍可沿原路连退。

### 5.1 过共享边 Crossing

对 **每一段** `上一点 → 当前点`：

1. **短段不扫边。** 段长 `< 0.45 * unit` 只跑第 6 节。按下当帧只认第一格。  
2. 看队尾 **四邻** 里合法（同色、未在名单、不是上一格）的格。  
3. 线段与 **队尾–该邻的共享边** 相交则记 `t ∈ [0,1]`。对角邻居不在候选里。  
4. 按 `t` 从小到大把该邻居加入名单。过角同时碰到两条边时：轴滞回（来时轴优先，直到另一轴 × `PATH_AXIS_STICK` 更大），否则 `|Δx| ≥ |Δy|` 先横。加上则 `t` 下限提高，再扫新队尾。  
5. 本段终点再跑一次第 6 节（进格 + 减格）。

**禁止：** 用 Crossing 命中点调用 `stepPath`（同一点加了又减）。  
**禁止：** `t` 不增加仍继续扫。  
**禁止：** 圆盘扫八邻 / `PATH_CROSS_R` 点名对角。

---

## 6. 单点：加与减（`stepPath`）

对每个插值点：先尝试 **加一格**；加不成再尝试减（减可连退）。加成功则结束本点（最多加一格）。

### 6.1 尾格死区

队尾格心到手指 `< 0.45 * unit` → **加、减都不做**，结束本点。格内晃动不变名单。

### 6.2 四邻（只问横竖）

只考虑队尾的 **上 / 下 / 左 / 右**。对角 `|Δrow|=1 且 |Δcol|=1` 非法。

**进格：** 手指落在某四邻的格子矩形内（共享边算进邻格）。  
**过边：** 沿队尾心 → 该邻心的投影 `t >= 0.5`，且距该邻心 ≤ **2.5 × 该步格心距**（手指还没进矩形、但已越过共享边时的后备）。

多格同时满足（过角）：

- 已有来时轴：另一轴分量 ≤ 来时轴 × `PATH_AXIS_STICK`（1.2）则保持来时轴。  
- 否则 `|Δx| ≥ |Δy|` 取横，否则取竖。

不要量化成八向扇区，不要整划锁死一根轴。

### 6.3 加格（先于减）

同时满足才加：

1. `next` 是四邻、不是上一格、在盘内、不在路径中。  
2. 颜色 = 锁定色，**或** 是道具（变色 / 魔法），**或** 刚连过道具（下一格可换色），**或** 本划已连上魔法（任意非空格）。细则 [ITEMS.md](./ITEMS.md)。  
3. 进格 **或** 过共享边（§6.2）。  

加上后 **结束本点**（禁止同一指尖位置连跳两格）。

### 6.4 减格

加不了才减。只能退 **上一格**：

1. 手指到上一格心 + `0.02*unit` 的平方 < 到队尾心的平方（过中线，比加格松）。  
2. 手指到上一格心 ≤ **1.2 × |上一格心-队尾心|**（必须在上一格旁边）。

满足则弹出队尾，`continue`（沿原路可连退）。  
不满足则结束本点。

**禁止：** 点到路径上任意已选格就收到那里；用「比上一格近」但不限制距离（手指在起点会一次退光整链）。

中部格子不可再加入队。对角交叉不再发生（对角不能入队）。

## 7. 抬手与表现

- 抬手点按第 5–6 节再跑一遍。  
- `path.length >= 2` 且路径上 stable 格 ≥ 2：有效，消除并下落。HUD 一次滚到取整后的累计（见 DESIGN）。生成与结算见 [ITEMS.md](./ITEMS.md)。选中/缩没/合成飞入见 [FEEDBACK.md](./FEEDBACK.md)。  
- `< 2`：名单清空，高亮去掉，HUD 滚回累计（预览作废）。  
- 下一划 `pointerdown` 清掉上一划有效态。  
- 真取消：同 `< 2`。

## 8. 常数表（手感锁）

| 符号 | 值 | 作用 |
|------|----|------|
| 点中半径 | `0.8 * unit` | 仅第一格 |
| `PATH_DEADZONE` | 0.45 | 尾格核，格内晃 |
| `PATH_AXIS_STICK` | 1.2 | 过角改轴：另一轴须大于来时轴 × 此值 |
| `PATH_ADD_ALONG` | 0.5 | 过共享边（沿该步投影） |
| `PATH_ADD_NEAR` | 2.5 | 过边时距目标心上限（×该步长） |
| `PATH_RETRACT_BIAS` | 0.02 | 减格过中线（×unit） |
| `PATH_NEAR_STEP` | 1.2 | 减格须在上一格旁（×该步长） |
| `PATH_TRACE_STEP` | 0.4 | 插值步长（×unit） |
| `PATH_MIN` | 2 | 抬手有效 |

改其中一项必须跑第 10 节验收。不要改回八向扇区或整划轴锁。

## 9. 禁止实现（手感会偏）

| 做法 | 手感后果 |
|------|----------|
| 按下预筛四邻或整片同色 | 不能拐弯，或跳格 |
| 全盘最近格 / 四邻谁近加谁 | 过角乱加，不按过边顺序 |
| 八向扇区 / 对角邻居 | 田字连对角，与四向规则冲突 |
| 整划 `directionalLock` 锁死一轴 | 同一划不能拐 L |
| 先减后加 | 多同色：加上立刻退掉 |
| 减格不限制「在上一格旁」 | 移到起点整链退光 |
| 点链上任意格缩短 | 密盘擦到自己走过的格 |
| 插值用 8-supercover 直接加格 | 过角吃对角格 |
| `preciseLocation` 进格 | 与系统 hit-test 不一致 |
| 热路径 `new Audio()` | 与工程约定冲突 |

## 10. 验收（手感一致才算过）

1. **点中：** 格心按下亮 1；缝上可先不亮；框上滑入第一格正确。  
2. **格内晃：** 不离 0.45 格核不加减。  
3. **直线同色：** 快划三格以上应能连上，不无故跳格。  
4. **田字格斜划** 左下→右上：走楼梯（先横后竖或先竖后横），**不连对角**。  
5. **田字格直角** 左下→右下→右上：即使很快，拐角格仍在，不会被斜线吃掉。  
6. **回退：** 沿原路滑回上一格才减；飞到起点附近整链仍在（只剩想退时才一格格退）。  
7. **拐弯：** 四向可拐；对角不能入队；中部格子不能再入。  
8. **抬手：** 1 格取消；≥2 消除。邻列下落时静止子仍可划。触屏抬手后 **120ms** 内再按下续同一划。  
9. **第二指：** 不结束第一划（真机）。  
10. **盘外按下：** 不开始。
