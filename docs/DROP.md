# 下落与格子状态

本玩法：**抬手消路径 → 补满盘面**。无交换、无落地后再自动三消。  
路径只认 `stable`；邻列在掉时，已静止的子仍可划、抬手消。

数字真源：`src/game/design.ts` 的 `LOOK.dropV0` / `dropAccel` / `dropVMax`。设置面板可临时覆盖。实现：`src/game/drop.ts`。  
合成飞入何时一起腾格、道具格锁定见 [FEEDBACK.md](./FEEDBACK.md)。

## 两层分开

| 层 | 做什么 | 不做什么 |
|----|--------|----------|
| **格子** | 一格一子；`current` + `incoming`；只订下一行；走满 0.22 才腾源格 | 不管飞多快 |
| **运动** | 每帧 `v += a·dt`，封顶；初速决定少格 | 不用刚体引擎 |

## 格子

| 槽 | 含义 |
|----|------|
| `current` | 谁占着这格 |
| `incoming` | 谁订了这格、还没落地 |

**正下方一格能接，才打开上方的子**，目标永远是下一行，到了再订下一格。

**空（`canReceiveDrop`）**：`current` 与 `incoming` 都空（队尾若在等道具弹出，该格也不空）。  
**不空**：还有 current（含已在掉但没走出 0.22 格）、还有 incoming、或正在 `clearing`。

合成飞入的腾格时机见 [FEEDBACK.md](./FEEDBACK.md)：路径格到点一起放空；只锁道具格，不锁整列。

源格变空：子相对格心向下走满 **0.22 格**。

棋子状态：`stable` / `dropping` / `clearing` / `spawning`。落地直进 `stable`。  
路径只认 `stable`。下落 / 消除 / 生成中的子不可划。

## 运动

同一套初速 / 加速度 / 上限。列与列独立。顶补与盘内静起用同一初速。

| 参数 | 设计默认 | 设置名 | 作用 |
|------|----------|--------|------|
| 初速度 | **600** px/s | 初速度 | 一开始有多快；少格几乎只看这个 |
| 加速度 | **1400** px/s² | 加速度 | 掉着掉着加多快；多格才明显 |
| 速度上限 | **1600** px/s | 速度上限 | 最快能到多少；太长就顶住 |
| 释放源格 | 0.22 格 | （固定） | 腾源格，让上方跟上 |
| 软间距 | 0.85 格 | （固定） | 贴下方减速，不推顶 |
| 动量窗 | 落地 50ms | （固定） | 再掉可继承速度 |
| 吸附 | 3 px | （固定） | 贴格心 |

运行时上限不会低于初速度。不要用刚体。

道具占格，下落上与普通子相同（`current` / `incoming`）。生成与结算见 [ITEMS.md](./ITEMS.md)。
