# 滑动路径

本游戏是 **可拐弯的同色四向路径**，不是划词直线，不是八向。  
**实现手感（算法、常数、验收）以 [OPERATION.md](./OPERATION.md) 为准。** 下文是规则摘要。

对照 SlidetoWord 只借：**第一指、框内按下滑入才起点、松手再采一次、`pointercancel` 不结束第一划、浅格 rect 点中、`lockGestures`**。  
不借：整划一条 8 向射线、`along`、粘住角、认词终点门。

实现：`src/game/input.ts`（第一指）· `src/game/path.ts`（名单）· `src/game/mount.ts`（接线）。

## 一次手势

| 段 | 做什么 |
|----|--------|
| **按下** | 只定第一格和颜色。点中：浅格区 rect，最近格心，半径 **格宽 × 0.8**，且该格 `stable`。按下没有 0.45 死区。框上/缝里可以没有第一格，滑近再认。棋盘外（HUD、letterbox）按下不开始。只认第一指。 |
| **滑动** | 每次新位置都从 **当前队尾** 再判。先加后减。滑动中不消子。出格子区冻结尾，手势仍在。 |
| **抬手** | 用松手点再判一次。stable 同色 ≥ 2 有效并消除，&lt; 2 取消。 |
| **取消** | 第二指引起的 `pointercancel` 续划；没有 touch 备份才解散。 |

## 滑动：加格

按下**不会**预筛「能加哪些格」。下一步取决于队尾在哪。

只问 **队尾的四邻**（不是全盘最近格，也不是四邻谁近加谁）：

1. 手指进入该邻格，或越过队尾与该邻的共享边。对角非法。  
2. 过角两条边同时碰到：轴滞回（`PATH_AXIS_STICK`），否则主轴优先，走楼梯。  
3. 同色、不在路径里、不是上一格。  
4. 过边后备：沿该步投影 ≥ 0.5 且距邻心 ≤ **2.5 × 这一步格心距**。

能加则加，**先加后减**。一次采样可以沿同一方向连加多格，每步仍只走一格，禁止跳格。

两次采样之间按 **0.4 格** 插值；**两轴都跳得远时走直角折线**（有来时方向则先沿该四向；否则主轴优先）。每点最多加一格。有合批点则先展开。插值不是 8-supercover 直接加格。

田字格四同色、左下→右上：楼梯（横+竖），不连对角。

## 滑动：减格

只能缩短这条链，不能从中间抽格。

- 只退 **上一格**（倒数第二个）。  
- 手指比队尾心 **更靠近上一格**（滞回 0.02 格，比加格松，沿原路退得及时）。  
- 必须在上一格旁边（同样 1.2 倍格心距）。手指在起点、队尾在远处 → **整链不动**。  
- 沿原路往回时，一次采样可以连退多格。  
- **不**做「点到链上任意已选格就收到那里」。

路径中部不可再加入队。对角不能入队，交叉不再发生。

## 尾格死区

已有队尾后：距尾格心 **&lt; 0.45 格** → 加、减都不做（格内晃动）。这不是按下点中圈。

## 刻意不做（已踩过的坑）

| 坑 | 为什么不做 |
|----|------------|
| 按下时筛四邻或整片同色 | 不能拐弯，或会跳格 |
| 用全盘 `cellFromLocal` 或四邻谁近加谁 | 过角不按边的顺序 |
| 八向扇区 / 对角邻居 | 田字连对角 |
| 整划锁轴 | 不能拐 L |
| 先减后加 | 多同色区：加上立刻退掉，看起来漏格 |
| 「比上一格近」不限制距离 | 手指移到起点，半盘都算靠近上一格，一次退光 |
| 点链上任意格缩短 | 密盘很容易擦到自己走过的格 |

## 常数

| 名 | 值 | 用在 |
|----|----|------|
| 点中半径 | 格宽 × 0.8 | 仅第一格 |
| `PATH_DEADZONE` | 0.45 格 | 尾格核 |
| `PATH_AXIS_STICK` | 1.2 | 过角改轴阈值 |
| `PATH_ADD_ALONG` | 0.5 | 加格：沿该向走过半步 |
| `PATH_ADD_NEAR` | 2.5 × 格心距 | 加格：快划上限 |
| `PATH_RETRACT_BIAS` | 0.02 格 | 减格过中线 |
| `PATH_NEAR_STEP` | 1.2 × 格心距 | 仅减格须在上一格旁 |
| `PATH_MIN` | 2 | 抬手有效 |
| `PATH_TRACE_STEP` | 0.4 格 | 采样间插值步长 |

震动/线宽仍以 SlidetoWord 为反馈阶段起点，不参与路径几何。
