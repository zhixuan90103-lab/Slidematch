# 滑动路径

本游戏是 **可拐弯的同色路径**，不是划词直线。

对照 SlidetoWord 只借：**第一指、盘外按下滑入才起点、松手再采一次、`pointercancel` 不结束第一划、棋盘 rect 点中、`lockGestures`**。  
不借：整划一条 8 向射线、`along`、粘住角、认词终点门。

## 一次手势

```
down   第一指；盘内或滑入的第一格 = 起点
move   尾格心 → 手指，量化八向
       邻格 ∧ 同色 ∧ 不在路径 → 追加
       当前格是路径倒数第二格 → 回退
       其它（跳格、异色、路径中部）→ 忽略
up     用松手点再算一次；长度 ≥ 3 则结算，否则取消
cancel 真取消才丢掉；第二指引起的 pointercancel 继续第一划
```

只认第一指。`setPointerCapture`；iOS 上 cancel 后用 touch 通道续划（对照 `mount.ts`）。

## 死区 / 出盘 / 交叉（候选，B 落地时定）

| 项 | 候选 |
|----|------|
| 死区 | 距起点格心 0.45 格内不追加 |
| 出盘 | 冻结尾，不取消 |
| 自交 | 只许回退上一格 |
| 对角 X | 未定；B 可先允许、只禁跳格 |

## 对照常数（不直接当路径几何）

SlidetoWord：死区 0.45 格、线宽 0.75 格、press 震 I0.55 S0.86、过格 I0.35 S0.65。反馈阶段可作起点。
