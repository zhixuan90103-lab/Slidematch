# 滑动路径

本游戏是 **可拐弯的同色路径**，不是划词直线。

对照 SlidetoWord 只借：**第一指、框内按下滑入才起点、松手再采一次、`pointercancel` 不结束第一划、浅格 rect 点中、`lockGestures`**。  
不借：整划一条 8 向射线、`along`、粘住角、认词终点门。

实现：`src/game/input.ts`（第一指）· `src/game/path.ts`（名单）· `src/game/mount.ts`（接线）。

## 一次手势

| 段 | 做什么 |
|----|--------|
| **按下** | 只定第一格和颜色。点中：浅格区 rect，最近格心，半径 **格宽 × 0.8**。按下没有 0.45 死区。框上/缝里可以没有第一格，滑近再认。棋盘外（桌面、HUD、letterbox）按下不开始。只认第一指。 |
| **滑动** | 每次新位置都从 **当前队尾** 再判。先加后减。滑动中不消子。出格子区冻结尾，手势仍在。 |
| **抬手** | 用松手点再判一次。长度 ≥ 3 有效（阶段 B 只留绿框），&lt; 3 取消。 |
| **取消** | 第二指引起的 `pointercancel` 续划；没有 touch 备份才解散。 |

## 滑动：加格

按下**不会**预筛「能加哪些格」。下一步取决于队尾在哪。

只问 **队尾指向手指的那一个八向邻居**（不是全盘最近格，也不是八邻里谁近加谁）：

1. 方向：尾格心 → 手指，量化成八向。已有上一格时，相对来时方向 **±30° 内粘住**，避免田字格斜划先吃掉横竖两格。  
2. 沿该方向走过 **一半格心距** 才加（斜向半距更长，不会先触发横/竖）。  
3. 同色、不在路径里、不是上一格。  
4. 手指距该邻居心 ≤ **2.5 × 这一步格心距**（允许快划连加，禁止隔着半盘加）。

能加则加，**先加后减**。一次采样可以沿同一方向连加多格，每步仍只走一格，禁止跳格。

两次系统采样之间按 **0.4 格** 插值，每点仍走上面的加/减（补快划漏格）。已有来时方向时，插值先沿该方向再拐弯，避免田字格直角被抄成对角线。有 `getCoalescedEvents` 时先展开合批点再插值。插值不是把线段切过的格直接加上。

田字格四同色、左下→右上：只连对角线，不加点另外两角。

## 滑动：减格

只能缩短这条链，不能从中间抽格。

- 只退 **上一格**（倒数第二个）。  
- 手指比队尾心 **更靠近上一格**（滞回 0.02 格，比加格松，沿原路退得及时）。  
- 必须在上一格旁边（同样 1.2 倍格心距）。手指在起点、队尾在远处 → **整链不动**。  
- 沿原路往回时，一次采样可以连退多格。  
- **不**做「点到链上任意已选格就收到那里」。

路径中部不可再加入队。对角 X：靠「方向认格」避免田字误触；两条对角交叉仍允许。

## 尾格死区

已有队尾后：距尾格心 **&lt; 0.45 格** → 加、减都不做（格内晃动）。这不是按下点中圈。

## 刻意不做（已踩过的坑）

| 坑 | 为什么不做 |
|----|------------|
| 按下时筛 8 邻或整片同色 | 不能拐弯，或会跳格 |
| 用全盘 `cellFromLocal` 或八邻谁近加谁 | 斜向被横竖抢走（田字格） |
| 先减后加 | 多同色区：加上立刻退掉，看起来漏格 |
| 「比上一格近」不限制距离 | 手指移到起点，半盘都算靠近上一格，一次退光 |
| 点链上任意格缩短 | 密盘八向很容易擦到自己走过的格 |

## 常数

| 名 | 值 | 用在 |
|----|----|------|
| 点中半径 | 格宽 × 0.8 | 仅第一格 |
| `PATH_DEADZONE` | 0.45 格 | 尾格核 |
| `PATH_STICK_DEG` | 30° | 来时方向粘滞 |
| `PATH_ADD_ALONG` | 0.5 | 加格：沿该向走过半步 |
| `PATH_ADD_NEAR` | 2.5 × 格心距 | 加格：快划上限 |
| `PATH_RETRACT_BIAS` | 0.02 格 | 减格过中线 |
| `PATH_NEAR_STEP` | 1.2 × 格心距 | 仅减格须在上一格旁 |
| `PATH_MIN` | 3 | 抬手有效 |
| `PATH_TRACE_STEP` | 0.4 格 | 采样间插值步长 |

震动/线宽仍以 SlidetoWord 为反馈阶段起点，不参与路径几何。
